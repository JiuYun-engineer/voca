# 단어 암기장

영어 단어를 범위별로 입력하고, 카드로 암기하고, 4지선답으로 시험 보는 웹앱.
설치·서버·인터넷 없이 동작하며 데이터는 브라우저에 저장됩니다.

## 구성 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (HTML·CSS·JS 한 파일) |
| `manifest.webmanifest` | 홈 화면 앱(PWA) 정보 |
| `sw.js` | 오프라인에서도 열리도록 캐시 |
| `icon.png` | 앱 아이콘 (`icon.svg`는 그 원본) |

## 사용법

- **단어 입력** — 폴더 → 범위 → 단어 구조. 범위에 단어 / 한국어 뜻 / 영어 동의어 / 연상법 입력.
  여러 개는 `단어 | 한국어뜻 | 동의어1, 동의어2 | 연상법` 형식으로 한 번에 붙여넣기.
- **단어 암기** — 카드의 뜻·동의어·연상법 칸을 누르면 가려집니다. ⌨️ 타이핑 시험으로 직접 쳐서 확인.
- **단어 시험** — 선택한 범위에서 4지선답 자동 출제. 10개씩 묶어서 부분만 볼 수도 있습니다.
  틀린 단어는 ⭐ 다시 볼 단어에 자동 저장.

### 폴더

범위는 폴더로 묶어 정리합니다. 폴더 안에 폴더도 만들 수 있습니다.

```
📁 Blueribbon SAT Word
  📁 Common Vocab
      Common Vocab 1~50 / 51~100 / 101~150 / 151~200
  📁 In-Class Vocab
      In-Class Vocab
```

폴더는 `상위/하위` 경로 문자열로 저장됩니다(`range.folder`). 📁+ 버튼에서 `A/B` 처럼
한 번에 여러 겹을 만들 수 있고, 범위의 📁 버튼으로 다른 폴더에 옮깁니다.
폴더를 지우면 안에 있던 범위는 상위 폴더(없으면 미분류)로 올라가고 단어는 남습니다.

목록은 어디서나 **abc·123 자연 정렬**입니다 — `Vocab 2` 가 `Vocab 10` 보다 앞에 옵니다.

### 10개씩 끊어 외우기

암기 탭의 **📚 10개씩 끊어 외우기**. 선택한 범위를 10·15·20개 묶음으로 끊어 두 단계로 진행합니다.

1. **익히기** — 그 10개를 뜻·동의어·연상법과 함께 펼쳐 놓고 읽습니다
2. **써보기** — 같은 10개를 단어만 남기고, 한국어 뜻과 영어 동의어를 직접 입력합니다
   (맞으면 초록색, 모르겠으면 빈칸에서 Enter → 정답 공개 + 오답 처리)
   - 철자가 조금 틀려도 맞게 처리합니다. `≈` 표시와 함께 정확한 철자를 보여줍니다
   - 채점이 틀렸다고 해도 **✓ 맞은 걸로** 버튼으로 직접 정답 처리할 수 있습니다
     (별표와 복습 단계도 맞힌 것으로 되돌립니다)
3. **결과** — 점수와 틀린 단어. `틀린 것만 다시` / `이 묶음 다시` / `다음 10개 →`

채점 결과는 ⭐와 [망각곡선 복습](#망각곡선-복습-간격-반복) 일정에 그대로 반영됩니다.

### 망각곡선 복습 (간격 반복)

시험이나 타이핑 시험에서 채점될 때마다 단어별 복습 일정이 갱신됩니다 (`db.srs`).

| 단계 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 다음 복습까지 | 지금 | 1일 | 3일 | 7일 | 14일 | 30일 | 60일 |

- 맞히면 한 단계 위로 → 복습 간격이 길어집니다
- 틀리면 0단계로 돌아가고 즉시 복습 대상이 되며 ⭐에도 담깁니다
- 두 번 연속 맞히면 ⭐에서 자동으로 빠집니다
- 한 번도 안 푼 단어는 항상 복습 대상입니다

시험 탭의 **🧠 망각곡선 복습 → 지금 복습 시작**, 또는 출제 대상을 **⏰ 오늘 복습할 단어**로
두면 복습할 때가 된 단어만 급한 순서대로 출제됩니다.
암기 탭의 **⏰ 복습할 단어만** 필터로 플래시카드도 복습 대상만 넘겨볼 수 있습니다.

### 시험 통과 조건 (2번 맞히기)

시험은 고정된 문항 목록이 아니라 **대기열**로 돌아갑니다.

- 맞히면 `1/2` 가 되고 **맨 뒤로** 보내져, 한 바퀴 뒤에 다시 나옵니다
- 그때 또 맞히면 **통과**되어 대기열에서 빠집니다
- 틀리면 **0으로 초기화**되고 맨 뒤로 가서, 다시 두 번을 맞혀야 합니다
- 대기열이 비면 시험이 끝납니다

통과 조건은 1·2·3번 중에 고를 수 있습니다(기본 2번).

### 묶음 시험

시험 탭의 **묶음으로 나눠 풀기**에서 10·20·25개씩 나누면 `1~10`, `11~20` … 칩이 생기고,
고른 묶음만 출제됩니다. 나누는 기준은 위의 정렬 순서라 암기 화면에서 본 순서와 같습니다.

## 기기 간 동기화

**단어 입력 → ☁️ 기기 간 동기화 → 동기화 켜기** 를 누르면 12자리 코드가 생깁니다.
다른 기기에서 `#sync=코드` 링크를 열거나 **기존 코드로 연결**에 코드를 넣으면,
그 뒤로는 단어와 ⭐가 양쪽에서 자동으로 맞춰집니다.

- 처음 연결할 때는 양쪽 단어를 **합칩니다**(같은 범위·같은 단어는 중복되지 않음)
- 이후에는 나중에 고친 쪽이 반영됩니다
- 인터넷이 없으면 로컬에만 저장했다가, 연결되면 자동으로 올라갑니다
- 코드를 아는 사람은 단어장을 보고 고칠 수 있으니 공개된 곳에 올리지 마세요

수동 백업이 필요하면 **📋 텍스트로 복사 / 📥 붙여넣어 복원**, **파일로 내보내기**도 그대로 쓸 수 있습니다.

### 동기화 서버 (Firebase)

| 항목 | 값 |
|---|---|
| 프로젝트 | `voca-sync-8d83d0-26961` |
| DB | Realtime Database (us-central1), 무료 Spark 요금제 |
| 보안 규칙 | [database.rules.json](database.rules.json) — `vaults/<12자 이상 코드>` 만 읽기·쓰기 허용, 목록 조회 차단 |

규칙을 고쳤다면 `firebase deploy --only database` 로 배포합니다.
`index.html` 안의 apiKey는 공개돼도 되는 값이며, 실제 접근 통제는 위 보안 규칙이 담당합니다.

## 폰에 앱으로 설치

- 아이폰(Safari): 공유 버튼 → `홈 화면에 추가`
- 안드로이드(Chrome): ⋮ → `앱 설치` 또는 `홈 화면에 추가`

## 수정 후 재배포할 때

`index.html`을 고친 뒤에는 `sw.js` 첫 줄의 캐시 이름 숫자를 올려야
기존 사용자 화면에도 새 버전이 반영됩니다. (`voca-v1` → `voca-v2`)
